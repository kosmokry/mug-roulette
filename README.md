# Кружка дня

Рулетка выбора кружки для кофе в стиле открытия сундуков Dota 2. Кружки собраны из фото (3D с фото-текстурой), розыгрыш идёт на одной сцене под барабаны.

Запуск локально: `python3 -m http.server 8765` → http://localhost:8765

`tools/build.py` — скрипт, который собирает развёртки и профили кружек из фото (нужны rembg, opencv, scipy).
